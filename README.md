# Sary Roast — демо-лендинг

Адаптивный лендинг вымышленной обжарки кофе из Алматы. Чистые HTML, CSS и JavaScript, без фреймворков, сборщиков и зависимостей. Бренд, цены и условия вымышлены, проект сделан для портфолио.

**Главная идея страницы.** В центре интерактивный профиль обжарки: ползунок двигает маркер по кривой температуры, и вместе с ним меняются цвет зерна, стадия, вкусовые ноты и подсветка участка графика. Кнопки «Показать профиль» в списке лотов переводят ползунок в точку, где остановили обжарку.


## Что показывает проект

**Вёрстка и адаптив**
- Семантическая разметка: `header`, `main`, `section`, `nav`, `ol`, `details`, `fieldset`, связанные `label`.
- Сетка на CSS Grid и Flexbox, брейкпоинты под телефон, планшет и десктоп.
- Дизайн-токены в `:root` (цвета, шрифты, отступы), текст масштабируется через `clamp()`.
- Две гарнитуры: Bricolage Grotesque для заголовков и Literata для текста.
- Список лотов: на десктопе строка таблицы, на телефоне перестраивается через `grid-template-areas`.

**JavaScript без библиотек**
- SVG-график строится кодом: кривая Катмулла — Рома, пересчёт под ширину контейнера через `ResizeObserver`, подписи осей адаптируются к экрану.
- Прорисовка кривой при загрузке через `stroke-dashoffset`.
- Форма с валидацией: сообщения об ошибках, фокус на первом неверном поле, `aria-invalid`, статус через `aria-live`.
- Бургер-меню, закрывается по `Escape`.

**Аналитика и CRM**
- События уходят в `window.dataLayer`, настройка тегов GA4 и Яндекс.Метрики делается в GTM.
- UTM-метки из адреса попадают в скрытые поля формы.
- Персональные данные в аналитику не отправляются.
- Отправка заявки сейчас заглушка (`sendLead` в `script.js`). Как подключить Битрикс24, описано в комментарии к функции.

**Доступность и производительность**
- Видимый фокус, ссылка «Перейти к содержимому», управление ползунком с клавиатуры.
- Учитывается `prefers-reduced-motion`.
- Нет изображений: зерно и график нарисованы в SVG. Ресурсов всего три файла и шрифты.
- Страница читаема без JavaScript, для графика есть текстовая подсказка в `noscript`.

## События для GTM

| Событие | Когда срабатывает | Параметры |
|---|---|---|
| `cta_click` | клик по кнопке с `data-cta` | `cta`, `cta_text` |
| `section_view` | секция просмотрена на 40% | `section` |
| `roast_slider_used` | ползунок отпущен или перестал двигаться | `roast_time`, `roast_stage` |
| `roast_preset_used` | клик по готовому профилю | `roast_time` |
| `lot_profile_view` | клик «Показать профиль» у лота | `lot`, `roast_time` |
| `faq_open` | раскрыт вопрос | `question` |
| `form_start` | первый фокус в форме | `form_id` |
| `form_error` | отправка с ошибкой | `form_id`, `field` |
| `generate_lead` | заявка отправлена | `form_id`, `plan`, `roast`, `grind` |

## Структура

```
index.html   разметка и тексты
styles.css   стили и дизайн-токены
script.js    график, меню, аналитика, форма
```
